## Usage

### For Video Templates:
1. Launch Adobe Premiere Rush.
2. Select **File** → **New Project** and load the provided template.
3. Explore the timeline and layers.
4. Replace placeholder media with your own footage.
5. Customize text and colors to match your brand.

### For Effects and Transitions:
1. Import the effect presets via the **Effects** panel.
2. Drag and drop presets between clips on the timeline.
3. Adjust duration and customize effect parameters.
4. Preview the applied effects in real-time.
5. Fine-tune using the **Effect Controls** panel.

### For Color Grading:
1. Open the **Color** panel.
2. Load the provided color presets.
3. Apply a preset to your clips.
4. Adjust intensity and additional color parameters.
5. Save custom color presets for future use.

### For Exporting:
1. Click the **Export** button in Premiere Rush.
2. Select the provided social media presets (YouTube, Instagram, TikTok).
3. Adjust video resolution, frame rate, and quality.
4. Click **Export** to generate your video.
